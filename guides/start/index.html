Getting started

So.. you decided you want to participate in PrintBoard? That's awesome! Let's guide you through making your first project:

Step 1: think of an idea

To build something, you need an idea!

Think about what you would like to display on your pegboard, once you get one. What is something you always lose and need a place to store? What do you think would look really cool hung up on a wall?

If you're not sure what to make, watch this YouTube video for inspiration!

Step 2: set up OnShape

Create an OnShape account and set up Hackatime for OnShape.

Step 3: start building!

Now that you're all set up, all that's left is to start building! If you have no experience in 3D CAD, check out some of the guides below.
